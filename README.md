# TripSync

---

Косталевский Даниил, БПИ-236

Приложение TripSync позволяет пользователям планировать путешествия, управлять бюджетом поездки, сохранять бронирования, планировать активности. Пользователь может создавать поездки, добавлять расходы, планировать мероприятия и хранить всю информацию о путешествии в одном месте.

Проект включает в себя слоистую архитектуру, тестирование и управление состоянием через Riverpod.

---

## Функциональность

*Onboarding*
При первом запуске приложение показывает onboarding с несколькими экранами, где описаны основные возможности приложения.

*Управление поездками*
Пользователь может:
- создавать поездки
- просматривать список всех поездок
- открывать детали поездки
- удалять поездки

Для каждой поездки отображается:
- место назначения
- даты путешествия
- общий бюджет
- потраченный бюджет
- количество активностей

*Бюджет поездки*

Пользователь может:
- добавлять расходы
- редактировать расходы
- удалять расходы
- просматривать список всех расходов

Также автоматически считается:
- общий бюджет поездки
- потраченная сумма

*Планирование поездки*

Пользователь может:
- добавлять активности
- планировать мероприятия
- управлять расписанием поездки

*Бронирования*

Пользователь может:

- добавлять бронирования (отели, билеты и т.д.)
- редактировать их
- удалять бронирования

Это позволяет хранить всю важную информацию о путешествии внутри приложения.

## Управление состоянием

Для управления состоянием используется
Riverpod.

*Основные контроллеры:*
- TripsController
- BudgetController
- BookingsController

## Тестирование

В проекте реализованы unit tests.

Протестированы:
- TripsController
- BudgetController
- BookingsController
- работа Riverpod providers

Тесты проверяют:
- добавление элементов
- обновление данных
- удаление
- корректность состояния

Все тесты запускаются командой flutter test
